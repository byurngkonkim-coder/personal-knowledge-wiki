## 📖 Essential Stems & Affixes: Unit 2.2 - Essential Suffixes

### 1. 🧭 단원 개요 및 핵심 학습 목표 (Overview & Targets)
- **주요 학습 테마**: 영어의 핵심 접미사(Suffixes)를 통해 단어의 품사(명사, 동사, 형용사, 부사)를 파악하고 의미를 유추하는 능력 향상.
- **원어민 사고방식 핵심 요약**: 접미사는 단어의 의미를 미묘하게 변화시키거나, 특정 품사로 전환하는 강력한 도구입니다. 원어민은 접미사를 통해 단어의 기능과 뉘앙스를 직관적으로 이해하며, 이를 통해 어휘력을 확장하고 문맥을 정확히 파악합니다. 이 단원에서는 다양한 접미사의 기능과 활용을 익혀 어휘 확장 및 독해/작문 능력을 향상시키는 것을 목표로 합니다.

### 2. 🎯 핵심 공식 & 원어민 뉘앙스 매트릭스 (Rule & Nuance Matrix)

| 구분 / 유닛 | 핵심 공식 & 구조 | 원어민 실제 뉘앙스 & 용법 | 한국인 학습자 단골 함정 (Pitfalls) |
|---|---|---|---|
| **형용사 접미사 (Adjective Suffixes)** | | | |
| `-able`, `-ible` | 동사/명사 + `-able`/`-ible` → 형용사 (할 수 있는, ~할 가치가 있는) | 가능성, 적합성, 가치 표현. `affordable` (감당할 수 있는), `visible` (볼 수 있는) | `-able`과 `-ible`의 철자 구분 어려움 (대부분 `-able`, `-ible`은 라틴어 어원). `*affordible` (X) |
| `-en` (동사화) | 형용사 + `-en` → 동사 (~하게 만들다) | 상태 변화, 약화/강화 의미. `weak` → `weaken` (약화시키다) | 형용사와 동사의 혼동. `*weakness` (명사)와 `weaken` (동사) 구분. |
| `-ify` | 명사/형용사 + `-ify` → 동사 (~화하다, ~으로 만들다) | 분류, 변형의 의미. `class` → `classify` (분류하다) | 동사화 접미사 `-ize`, `-ate` 등과의 미묘한 뉘앙스 차이 간과. |
| `-ize` | 명사/형용사 + `-ize` → 동사 (~화하다, ~으로 만들다) | 특정 상태로 만들거나, 특정 행위를 하다. `penalty` → `penalize` (처벌하다) | 영국식 `-ise`와 미국식 `-ize` 철자 혼동. |
| `-ate` (동사화) | 명사/형용사 + `-ate` → 동사 (~하게 만들다) | 필요성, 촉발의 의미. `necessity` → `necessitate` (필수화하다) | 형용사 접미사 `-ate` (열정적인)와 혼동 주의. |
| `-ful` | 명사 + `-ful` → 형용사 (~으로 가득 찬, ~이 많은) | 긍정적/부정적 특성 강조. `respect` → `disrespectful` (무례한) | `full`과 혼동. `*respectfull` (X) |
| `-less` | 명사 + `-less` → 형용사 (~이 없는) | 결핍, 부족의 의미. `count` → `countless` (무수한) | `less` (더 적은)와 혼동. |
| `-ic`, `-ical` | 명사 + `-ic`/`-ical` → 형용사 (~의, ~적인) | 특정 분야, 주기, 유형 관련. `period` → `periodic` (주기적인), `type` → `typical` (전형적인) | 의미 차이 없이 사용되기도 하지만, 때로는 미묘한 뉘앙스 차이 (예: `historic` vs `historical`). |
| `-ly` (형용사) | 명사 + `-ly` → 형용사 (~같은, ~의) | 명사에서 파생된 형용사. `cost` → `costly` (비싼) | 부사 `-ly`와 혼동 (형용사 + `-ly` → 부사). `*costly`를 부사로 오해. |
| `-ous` | 명사 + `-ous` → 형용사 (~이 많은, ~한) | 풍부함, 특성 강조. `vary` → `various` (다양한) | 철자 오류 (`*varius`). |
| `-(u)al` | 명사 + `-(u)al` → 형용사 (~의, ~적인) | 관련성, 특성 표현. `intellect` → `intellectual` (지적인) | `actual`과 같은 기존 단어와 혼동. |
| `-ant`, `-ent` | 동사 + `-ant`/`-ent` → 형용사 (하는, 하는 경향이 있는) | 행위의 주체나 상태 표현. `hesitate` → `hesitant` (주저하는), `depend` → `dependent` (의존적인) | 명사 접미사 `-ant`, `-ent` (행위자)와 혼동 주의. |
| `-ate` (형용사) | 명사 + `-ate` → 형용사 (~적인, ~을 가진) | 특성, 상태 표현. `passion` → `passionate` (열정적인) | 동사 접미사 `-ate`와 혼동 주의. |
| `-ite` | 명사 + `-ite` → 형용사 (~의, ~적인) | 반대, 특성 표현. `oppose` → `opposite` (반대의) | |
| `-ish` | 명사/형용사 + `-ish` → 형용사 (~같은, ~경향이 있는, ~색깔의) | 유사성, 경향, 색조 표현. `yellow` → `yellowish` (누런) | 다소 비격식적인 뉘앙스를 가질 수 있음. |
| `-ar(y)`, `-ory` | 명사 + `-ar(y)`/`-ory` → 형용사 (~의, ~적인) | 관련성, 특성 표현. `custom` → `customary` (관습적인), `satisfaction` → `satisfactory` (만족스러운) | |
| `-ive`, `-ative` | 동사 + `-ive`/`-ative` → 형용사 (~하는 경향이 있는, ~적인) | 능력, 특성 표현. `defect` → `defective` (결함이 있는), `imagine` → `imaginative` (상상력이 풍부한) | |
| `-y` | 명사 + `-y` → 형용사 (~한, ~이 많은) | 특성, 상태 표현. `health` → `healthy` (건강한) | |
| `-like` | 명사 + `-like` → 형용사 (~같은) | 유사성, 특징 표현. `child` → `childlike` (어린애 같은) | `childish` (유치한)와 `childlike` (천진난만한)의 긍정/부정 뉘앙스 차이. |
| **명사 접미사 (Noun Suffixes)** | | | |
| `-er`, `-ee`, `-or`, `-ant`, `-ent`, `-ist`, `-ive`, `-ary` | 동사/명사 + 접미사 → 명사 (행위자, 대상, 직업) | 행위의 주체, 대상, 직업을 나타냄. `manufacture` → `manufacturer` (제조업자), `employ` → `employee` (피고용인), `operate` → `operator` (작업자), `consult` → `consultant` (상담가), `respond` → `respondent` (응답자), `motor` → `motorist` (운전자), `represent` → `representative` (대표자), `mission` → `missionary` (선교사) | 각 접미사별로 특정 어원이나 분야에서 주로 사용되는 경향이 있음. |
| `-ion`, `-(a)tion`, `-ance`, `-ence`, `-(e)ty`, `-ity`, `-y`, `-ry`, `-al`, `-ure`, `-ment`, `-ness`, `-(a)cy`, `-th` | 동사/형용사 + 접미사 → 명사 (행위, 상태, 특성) | 행위, 상태, 특성을 나타내는 추상 명사. `inspect` → `inspection` (조사), `consider` → `consideration` (고려), `perform` → `performance` (수행), `prefer` → `preference` (선호), `anxious` → `anxiety` (걱정), `secure` → `security` (안전), `recover` → `recovery` (회복), `brave` → `bravery` (용감함), `approve` → `approval` (승인), `press` → `pressure` (압력), `achieve` → `achievement` (성취), `ill` → `illness` (질병), `literate` → `literacy` (읽고 쓸 줄 앎), `wide` → `width` (폭) | 다양한 접미사들의 철자 및 발음 변화에 주의. |
| `-ship` | 명사 + `-ship` → 명사 (상태, 관계, 기술) | 관계, 자격, 기술을 나타냄. `member` → `membership` (회원 자격), `sportsman` → `sportsmanship` (스포츠맨십) | |
| `-ism` | 명사 + `-ism` → 명사 (주의, 학설, 특성) | 사상, 주의, 특성을 나타냄. `professional` → `professionalism` (전문가 기질), `volunteer` → `volunteerism` (자원봉사 활동) | |
| `-hood` | 명사 + `-hood` → 명사 (상태, 시기, 집단) | 상태, 시기, 집단을 나타냄. `adult` → `adulthood` (성인기), `neighbor` → `neighborhood` (이웃) | |
| **부사 접미사 (Adverb Suffixes)** | | | |
| `-ly` (부사) | 형용사 + `-ly` → 부사 (~하게) | 방식, 정도를 나타냄. `quick` → `quickly` (빠르게), `near` → `nearly` (거의) | 명사 + `-ly` (형용사)와 혼동 주의. `*costly` (형용사)를 부사로 오용. |
| `-ward` | 명사/방향 + `-ward` → 부사 (방향) | 특정 방향으로. `fore` → `forward` (앞으로) | |
| `-wise` | 명사 + `-wise` → 부사 (~방향으로, ~에 관하여) | 방향, 방식, 관점을 나타냄. `clock` → `clockwise` (시계 방향으로) | |

### 3. 🏋️ 실전 연습문제 & 인터랙티브 자가 점검 드릴 (Interactive Practice Drills)

#### **문제 1**
Without protection, such industries might be _______ by foreign competition.
a) weak
b) weakness
c) weaken
d) weakened

||[정답] d) weakened||

**💡 상세 해설 & 오답 분석**:
- **정답 이유**: 문맥상 '외국 경쟁에 의해 약화될 수 있다'는 수동태 표현이 필요합니다. `might be` 뒤에는 동사의 과거 분사형이 와야 수동태를 이룹니다. `weaken`은 동사이고, `weakened`는 `weaken`의 과거 분사형이므로 적절합니다.
- **오답 보기 분석**:
  - a) `weak`: 형용사입니다. `might be weak`은 가능하지만, '약화되다'라는 동사적 의미를 표현하기에는 부족합니다.
  - b) `weakness`: 명사입니다. 문맥상 명사가 올 자리가 아닙니다.
  - c) `weaken`: 동사의 원형입니다. `might be weaken`은 문법적으로 틀린 표현입니다 (조동사 `be` 뒤에는 동사원형이 올 수 없습니다. `might weaken`은 가능하지만, 수동태 의미를 담지 못합니다).

#### **문제 2**
It is a human trait to try to define and _______ the things.
a) class
b) classy
c) classify
d) classification

||[정답] c) classify||

**💡 상세 해설 & 오답 분석**:
- **정답 이유**: `to define and _______`에서 `define`과 병렬 구조를 이루는 동사가 필요합니다. `classify`는 '분류하다'라는 동사입니다.
- **오답 보기 분석**:
  - a) `class`: 명사 (계급, 수업) 또는 동사 (분류하다)로 쓰일 수 있으나, 여기서는 `classify`가 더 자연스러운 동사 형태입니다.
  - b) `classy`: 형용사 (고급스러운)입니다. 문맥상 동사가 필요합니다.
  - d) `classification`: 명사 (분류)입니다. `to define and classification`은 문법적으로 맞지 않습니다.

#### **문제 3**
The state of Quebec, Canada, _______ individuals for speaking English and forbade English street signs.
a) penalty
b) penalize
c) penalized
d) penalizing

||[정답] c) penalized||

**💡 상세 해설 & 오답 분석**:
- **정답 이유**: 문장 전체의 시제가 과거(`forbade`)이므로, 병렬 구조를 이루는 동사도 과거형이 되어야 합니다. `penalize`의 과거형은 `penalized`입니다.
- **오답 보기 분석**:
  - a) `penalty`: 명사 (처벌)입니다. 동사가 필요한 자리입니다.
  - b) `penalize`: 동사 원형입니다. 문맥상 과거 시제가 필요합니다.
  - d) `penalizing`: 현재분사 또는 동명사입니다. 문장의 주어 `The state of Quebec`에 대한 주동사가 필요합니다.

#### **문제 4**
These choices involve "tradeoffs" and _______ an awareness of consequences of those tradeoffs.
a) necessity
b) necessary
c) necessitate
d) necessarily

||[정답] c) necessitate||

**💡 상세 해설 & 오답 분석**:
- **정답 이유**: `involve`와 병렬 구조를 이루는 동사가 필요합니다. `necessitate`는 '필수화하다, 필요하게 만들다'라는 동사입니다.
- **오답 보기 분석**:
  - a) `necessity`: 명사 (필요성)입니다. 동사가 필요한 자리입니다.
  - b) `necessary`: 형용사 (필요한)입니다. 동사가 필요한 자리입니다.
  - d) `necessarily`: 부사 (반드시)입니다. 동사가 필요한 자리입니다.

#### **문제 5**
With the evolution of mass production in the 19th century, musical instruments came to be _______ to the public at large.
a) afford
b) affordable
c) affording
d) affordability

||[정답] b) affordable||

**💡 상세 해설 & 오답 분석**:
- **정답 이유**: `came to be` 뒤에는 형용사가 와서 '어떤 상태가 되다'라는 의미를 만듭니다. `affordable`은 '감당할 수 있는'이라는 형용사입니다.
- **오답 보기 분석**:
  - a) `afford`: 동사 (여유가 있다)입니다. `to be afford`는 문법적으로 틀립니다.
  - c) `affording`: 현재분사 또는 동명사입니다. 문맥상 형용사가 필요합니다.
  - d) `affordability`: 명사 (감당할 수 있음)입니다. `to be affordability`는 문법적으로 틀립니다.

#### **문제 6**
These _______ forces directly affect our well-being.
a) visible
b) invisible
c) visibility
d) invisibly

||[정답] b) invisible||

**💡 상세 해설 & 오답 분석**:
- **정답 이유**: 문맥상 '보이지 않는 힘'이라는 의미가 되어야 합니다. `forces`를 수식하는 형용사가 필요하며, `invisible`은 '보이지 않는'이라는 뜻의 형용사입니다.
- **오답 보기 분석**:
  - a) `visible`: '보이는'이라는 뜻의 형용사로, 문맥상 반대 의미입니다.
  - c) `visibility`: 명사 (가시성)입니다. 형용사가 필요한 자리입니다.
  - d) `invisibly`: 부사 (보이지 않게)입니다. 형용사가 필요한 자리입니다.

#### **문제 7**
Argument is often considered _______ in rigid families.
a) disrespect
b) disrespectful
c) disrespectfully
d) disrespectfulness

||[정답] b) disrespectful||

**💡 상세 해설 & 오답 분석**:
- **정답 이유**: `considered` 뒤에는 목적 보어로 형용사가 와서 '어떠하다고 여겨지다'라는 의미를 만듭니다. `disrespectful`은 '무례한'이라는 형용사입니다.
- **오답 보기 분석**:
  - a) `disrespect`: 명사 (무례) 또는 동사 (무례하게 대하다)입니다. 형용사가 필요한 자리입니다.
  - c) `disrespectfully`: 부사 (무례하게)입니다. 형용사가 필요한 자리입니다.
  - d) `disrespectfulness`: 명사 (무례함)입니다. 형용사가 필요한 자리입니다.

#### **문제 8**
it may be affected directly or indirectly in _______ different ways by other plants and animals around it.
a) count
b) counted
c) countless
d) counting

||[정답] c) countless||

**💡 상세 해설 & 오답 분석**:
- **정답 이유**: `different ways`를 수식하는 형용사가 필요합니다. 문맥상 '무수히 많은'이라는 의미가 적절하며, `countless`는 '셀 수 없는, 무수한'이라는 형용사입니다.
- **오답 보기 분석**:
  - a) `count`: 동사 (세다) 또는 명사 (셈)입니다. 형용사가 필요한 자리입니다.
  - b) `counted`: 동사의 과거형 또는 과거분사입니다. 형용사가 필요한 자리입니다.
  - d) `counting`: 현재분사 또는 동명사입니다. 형용사가 필요한 자리입니다.

#### **문제 9**
Our youngsters are ignorant of Latin, put Mussolini in the same category as Dostoevski and cannot recite the _______ Table by heart.
a) period
b) periodic
c) periodical
d) periodically

||[정답] b) periodic||

**💡 상세 해설 & 오답 분석**:
- **정답 이유**: `Table`을 수식하는 형용사가 필요합니다. '주기율표'는 영어로 `Periodic Table`입니다. `periodic`은 '주기적인'이라는 형용사입니다.
- **오답 보기 분석**:
  - a) `period`: 명사 (기간, 주기)입니다. 명사 앞에 명사가 오는 복합 명사도 가능하지만, `Periodic Table`이 고유한 표현입니다.
  - c) `periodical`: 명사 (정기 간행물) 또는 형용사 (정기적인)로 쓰일 수 있으나, `Periodic Table`이 정확한 용어입니다.
  - d) `periodically`: 부사 (주기적으로)입니다. 형용사가 필요한 자리입니다.

#### **문제 10**
A _______ example of this is to wrap wedding gifts.
a) type
b) typical
c) typically
d) typify

||[정답] b) typical||

**💡 상세 해설 & 오답 분석**:
- **정답 이유**: `example`을 수식하는 형용사가 필요합니다. '전형적인 예'라는 의미로 `typical`이 적절합니다.
- **오답 보기 분석**:
  - a) `type`: 명사 (유형)입니다. `type example`은 어색합니다.
  - c) `typically`: 부사 (전형적으로)입니다. 형용사가 필요한 자리입니다.
  - d) `typify`: 동사 (전형이 되다)입니다. 형용사가 필요한 자리입니다.

### 4. 🧠 핵심 문장 암기 & 스피킹 훈련 매트릭스 (Key Sentence Mastery Matrix)

| 번호 | 영문 실전 문장 | 자연스러운 한국어 번역 | 핵심 문법 & 발음 팁 |
|:---:|---|---|---|
| 1 | Without protection, such industries might be **weakened** by foreign competition. | 보호가 없다면, 그런 산업들은 외국 경쟁에 의해 약화될 수 있습니다. | `weakened`는 `weaken`의 과거분사형으로 수동태를 이룹니다. `might be` 뒤에 `weakened`가 와서 '약화될 수도 있다'는 가능성을 나타냅니다. |
| 2 | It is a human trait to try to define and **classify** the things. | 사물들을 정의하고 분류하려는 것이 인간의 특성입니다. | `to define and classify`는 `to` 부정사 뒤에 동사 원형이 병렬로 연결된 구조입니다. `classify`는 '분류하다'라는 동사입니다. |
| 3 | The state of Quebec, Canada, **penalized** individuals for speaking English and forbade English street signs. | 캐나다 퀘벡주는 영어를 사용하는 사람들에게 벌금을 부과하고 영어 간판을 금지했습니다. | `penalized`는 `penalize`의 과거형으로, `forbade`와 시제를 일치시켜 병렬 구조를 이룹니다. |
| 4 | These choices involve "tradeoffs" and **necessitate** an awareness of consequences of those tradeoffs. | 이러한 선택들은 '타협'을 수반하며, 그러한 타협의 결과에 대한 인식을 필요로 합니다. | `involve`와 `necessitate`는 주어 `choices`에 대한 동사로 병렬 연결되어 있습니다. `necessitate`는 '필요하게 만들다'라는 동사입니다. |
| 5 | Musical instruments came to be **affordable** to the public at large. | 악기들이 일반 대중에게도 감당할 수 있는 가격이 되었습니다. | `came to be` 뒤에 형용사 `affordable`이 와서 '감당할 수 있는 상태가 되다'라는 의미를 만듭니다. |
| 6 | These **invisible** forces directly affect our well-being. | 이 보이지 않는 힘들이 우리의 행복에 직접적인 영향을 미칩니다. | `invisible`은 `forces`를 수식하는 형용사로 '보이지 않는'이라는 뜻입니다. |
| 7 | Argument is often considered **disrespectful** in rigid families. | 논쟁은 엄격한 가정에서는 종종 무례한 것으로 여겨집니다. | `considered` 뒤에 목적 보어로 형용사 `disrespectful`이 와서 '무례하다고 여겨지다'라는 의미를 형성합니다. |
| 8 | It may be affected directly or indirectly in **countless** different ways. | 그것은 무수히 많은 다양한 방식으로 직간접적인 영향을 받을 수 있습니다. | `countless`는 `different ways`를 수식하는 형용사로 '셀 수 없는, 무수한'이라는 의미입니다. |
| 9 | Our youngsters cannot recite the **Periodic** Table by heart. | 우리 젊은이들은 주기율표를 외우지 못합니다. | `Periodic Table`은 '주기율표'라는 고유명사입니다. `Periodic`은 '주기적인'이라는 형용사입니다. |
| 10 | A **typical** example of this is to wrap wedding gifts. | 이것의 전형적인 예는 결혼 선물을 포장하는 것입니다. | `typical`은 `example`을 수식하는 형용사로 '전형적인'이라는 의미입니다. |
