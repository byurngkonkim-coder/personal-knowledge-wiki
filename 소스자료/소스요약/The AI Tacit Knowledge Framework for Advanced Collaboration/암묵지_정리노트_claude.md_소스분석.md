## 💡 주요 용어 (Key Terminology)
- **SRM 협력모델**: 공급업체 관리 포탈(Supplier Relationship Management)의 성과 창출 가설 모델이었으나, 협력사 종속 구조와 자동화 한계 등의 3가지 자가 반론 기각 루프를 거치며 기각되고 '영세율 자동관리' 모델로 수렴함.
- **Aligned Forms (데이터 상속)**: 상위 전자무역 문서의 데이터를 하위 수신 문서나 연계 무역 신용장(예: DOMOFR \\(\rightarrow\\) PCRLIC, LOCADV)으로 자동 전달하고 상속시켜, 서류 간 불일치 비용과 입력 오류를 제로화하는 표준 데이터 정합성 설계 개념.
- **바이브코딩 (Vibe Coding)**: 코딩 전문 지식이 다소 취약한 비개발자 기획자가 Claude Code 및 터미널 자동화 스크립트를 효율적으로 구동하여 프로젝트 동기화 및 메타데이터를 정규화할 수 있도록 지원하는 7단계 매뉴얼 중심의 프로토콜 가이드.
- **정합성 검증 엔진 (Cross-Validation Engine)**: 이기종의 분산된 거래 시스템 간에 중복 제출되는 무역 금융 자료나 EDI 코드 불일치 데이터를 국제 표준 데이터 규격(UN/CEFACT, WCO)과 직접 대조하여 정합성 누락과 조작을 자동 판정하는 설계 사상.
