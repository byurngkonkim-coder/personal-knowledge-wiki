# 📄 Pattern English Speaking Training Textbook.md (Part: 전체)

## 📌 요약 (Executive Summary)
- 본 교재는 원어민이 일상 대화에서 빈번하게 구사하는 고빈도 영어 회화 패턴 162개를 엄선하여 수록한 입체적 패턴 말하기 훈련 교재이다 [1].
- 에빙하우스의 망각 곡선 이론에 최적화된 "누적 반복 학습 주기(당일 학습 ➡️ 10~20분 후 당일 복습 ➡️ 다음 날 1일 전 복습 ➡️ 이틀 후 2일 전 복습)"를 제안하여 단기 습득 정보의 영구 장기 기억 전환을 극대화한다 [1-3].
- 각 패턴마다 정합성 있는 5가지 원어민 상용 예문과 한글 해석 번역본을 대칭 병기하여, 단순 암기를 탈피하고 규칙적인 어순 뼈대에 다양한 품사를 자유롭게 변형 결착시키는 실전 구술 응용력을 배양한다 [1, 3].

## 🧱 상세 분해 (Detailed Breakdown)

### ### 1. 에빙하우스 망각 곡선 기반 누적 복습 가이드라인 및 교재 개요
- **핵심 논지**: 사람의 기억력이 초반에 급격히 감퇴하는 인지과학적 특성에 대응하여, 일정한 시차 복습 주기를 설계하고 한 개의 기본 패턴과 다섯 개의 예문 패턴 단위로 집중 훈련함으로써 회화 표현을 몸에 각인시키는 학습 이론이다 [1-3].
- **근거 및 데이터**:
  * **망각률 통계 지표**: 학습 후 10~20분 사이가 망각률이 가장 높으며, 1일 전 복습 시점(다음 날)에는 망각률이 67%까지 도달하고, 2일 전 복습 시점(이틀 후)에는 망각률이 72%까지 발생한다 [2, 3].
  * **누적 반복 4단계 가이드**:
    1. **당일 학습**: 그날의 새로운 패턴 하나와 다섯 개의 예문 패턴을 큰 소리로 반복하여 입에 안착시킨다 [2].
    2. **당일 복습**: 망각률이 최고조로 달하는 학습 후 10~20분 사이에 다시 한번 오늘 학습한 문장들을 큰 소리로 복습한다 [2].
    3. **1일 전 복습**: 하루 뒤에 전날 학습한 패턴 예문 전체를 다시 집중적으로 따라 하고 복습한다 [3].
    4. **2일 전 복습**: 이틀 뒤에 전전일 학습한 패턴과 예문 전체를 다시 들려주고 따라 하며 장기 기억 전환을 매듭짓는다 [3].
- **주요 인용**: > "제공된 소스에서 언급된 학습 방법은 에빙하우스의 망각 곡선 이론에 맞춰 최적화되어 있으며, 당일 학습, 당일 복습, 1일 전 복습, 2일 전 복습의 누적 반복 학습을 통해 장기 기억으로 유도합니다." [1]

### ### 2. 미래 계획, 시도, 임박, 선호 및 기본 의사 표현 패턴 (Pattern 1 ~ 22)
- **핵심 논지**: 자신의 즉각적이거나 장기적인 미래 행동 계획, 시도하는 상태, 특정 장소에 도달한 목적성, 완곡한 거절, 주관적 강점 및 열정적 선호를 전달하기 위해 사용하는 가장 기초적인 Be동사 및 일반동사 패턴군이다 [4, 5].
- **근거 및 데이터**:
  * **Pattern 1: I'm going to...** (~할 거야) ➡️ `work` (일할 거야) / `sleep` (잘 거야) / `eat` (먹을 거야) / `study` (공부할 거야) / `take a walk` (산책할 거야) [4].
  * **Pattern 2: I'm not going to...** (~안 할 거야) ➡️ `lie` (거짓말 안 할 거야) / `give up` (포기하지 않을 거야) / `study English` / `work today` / `read it` [4].
  * **Pattern 3: Are you going to...** (~할 거니?) ➡️ `stay?` / `sleep?` / `study?` / `do it?` / `the party?` [4, 5].
  * **Pattern 4: I'm trying to...** (~하려고 노력 중이야) ➡️ `sleep` / `understand` / `study` / `apologize` / `finish it` [5].
  * **Pattern 5: I'm not trying to...** (~하려던 게 아니야) ➡️ `ignore you` / `hurt you` / `tease you` / `be funny` / `complain` [5].
  * **Pattern 6: Are you trying to...** (~하려고 노력 중이니?) ➡️ `quit smoking?` / `find a job?` / `lose weight?` / `solve this problem?` / `make me angry?` [5].
  * **Pattern 7: I'm here to...** (~하러 여기에 왔어) ➡️ `travel` / `help` / `work` / `see Tom` / `study English` [5, 6].
  * **Pattern 8: I'm not here to...** (~하러 온 게 아니야) ➡️ `fight` / `compete` / `waste your time` / `make friends` / `judge anyone` [6].
  * **Pattern 9: I'm afraid...** (~인 것 같아 / 유감이지만 ~해) ➡️ `you're wrong` / `I can't help you` / `I'll be late` / `I don't have time` / `we can't go` [6].
  * **Pattern 10: I'm afraid of...** (~이 두려워) ➡️ `failure` / `the dark` / `heights` / `spiders` / `flying` [6, 7].
  * **Pattern 11: I'm good at...** (~을 잘해) ➡️ `English` / `cooking` / `playing basketball` / `singing` / `swimming` [7].
  * **Pattern 12: I'm about to...** (막 ~하려던 참이야) ➡️ `sleep` / `leave` / `go home` / `take a walk` / `watch a movie` [7].
  * **Pattern 13: I'm sick of...** (~에 질렸어) ➡️ `this cold weather` / `eating the same food every day` / `all the traffic in this city` / `hearing the same song` / `staying at home` [7].
  * **Pattern 14: I'm dying to...** (너무 ~하고 싶어) ➡️ `go on a vacation` / `go home` / `know the results` / `watch that movie` [7].
  * **Pattern 15: I'm ready to...** (~할 준비가 됐어) ➡️ `study` / `go` / `start` / `order` / `dance` [7].
  * **Pattern 16: Are you ready to...** (~할 준비 됐어요?) ➡️ `order?` / `go?` / `start?` / `take action?` / `take the exam?` [7].
  * **Pattern 17: I'm worried about...** (~이 걱정돼) ➡️ `the exam` / `the environment` / `my job` / `my parents' health` / `my friend` [7].
  * **Pattern 18: I'm interested in...** (~에 관심이 있어) ➡️ `design` / `cooking` / `Tom` / `your offer` / `the position` [7].
  * **Pattern 19: I'm getting...** (점점 ~해지고 있어) ➡️ `hot` / `tired` / `nervous` / `excited` / `healthy` [7].
  * **Pattern 20: I'm willing to...** (기꺼이 ~할 의향이 있어) ➡️ `learn` / `share` / `help you` / `wait here` / `work with them` [7].
  * **Pattern 21: I'm looking for...** (~을 찾고 있어) ➡️ `a new job` / `a key` / `my phone` / `a bus stop` / `my sunglasses` [7].
  * **Pattern 22: I want to...** (~하고 싶어) ➡️ `take a walk` / `go to sleep` / `be with you` / `know everything` / `visit Paris` [7].
- **주요 인용**: > "Pattern 4: I'm trying to...
I'm trying to sleep (나는 자려고 노력 중이야)
I'm trying to understand (나는 이해하려고 노력 중이야)" [5]

### ### 3. 욕구 기피, 권고, 과거 지향 소망 및 가치 판단 패턴 (Pattern 23 ~ 50)
- **핵심 논지**: 싫증이나 거부 의향 표명, 완곡하지만 단호한 권고(`You don't want to`), 사실과 반대되는 가정 소망, 그리고 사안의 중요성이나 가치를 수사적으로 분간할 때 사용하는 문형들이다 [8-10].
- **근거 및 데이터**:
  * **Pattern 23: I don't want to...** (~하고 싶지 않아) ➡️ `sleep` / `go home` / `make mistakes` / `tell you` / `be late` [11].
  * **Pattern 24: You don't want to...** (~하지 않는 게 좋을 거야) ➡️ `eat` (원본 기재 한글 해석 오타: "당신은게 좋을 거예요" 상태 보존) / `forget` / `know` / `do that` / `miss the opportunity` [11].
  * **Pattern 25: Do you want to...** (~하고 싶니?) ➡️ `stay?` / `leave?` / `go out?` / `watch a movie?` / `read this book?` [8, 11].
  * **Pattern 26: I just wanted to...** (단지 ~하고 싶었어) ➡️ `apologize` / `check` / `ask you` / `know the truth` / `thank you` [8, 11].
  * **Pattern 27: I think...** (내 생각에 ~해) ➡️ `it's important` / `she likes you` / `we need to talk` / `you're right` / `it's a good idea` [8, 11].
  * **Pattern 28: Do you think...** (~라고 생각하니?) ➡️ `I'm fat?` / `she's cute?` / `it's possible?` / `this is right?` / `I'm stupid?` [11].
  * **Pattern 29: I don't know why...** (내가 왜 ~하는지 모르겠어) ➡️ `I went there` / `I like this` / `I love you` / `I said that` / `I made a mistake` [11].
  * **Pattern 30: I didn't mean to...** (일부러 ~하려던 건 아니었어) ➡️ `upset you` / `hurt you` / `surprise you` / `scare you` / `cause trouble` [11].
  * **Pattern 31: I like your...** (네 ~이 마음에 들어) ➡️ `style` / `idea` / `smile` / `name` / `outfit` [11].
  * **Pattern 32: I like to...** (~하는 것을 좋아해) ➡️ `ski` / `sleep late` / `visit museums` / `listen to music` / `read a book` [11].
  * **Pattern 33: I don't like to...** (~하는 것을 좋아하지 않아) ➡️ `sing` / `wait` / `cook` / `study` / `exercise` [11, 12].
  * **Pattern 34: I don't have time to...** (~할 시간이 없어) ➡️ `study` / `exercise` / `explain` / `travel` / `cook` [9, 12].
  * **Pattern 35: I'd like to...** (~하고 싶어요) ➡️ `know more` / `order` / `ask you` / `thank you` / `see that` [9, 12].
  * **Pattern 36: Would you like to...** (~하시겠어요?) ➡️ `eat?` / `join us?` / `dance?` / `take a walk?` / `leave a message?` [9, 12].
  * **Pattern 37: Can I get...** (~ 주시겠어요?) ➡️ `a glass of water?` / `a refund?` / `a discount?` / `a ride?` / `some coffee?` [12].
  * **Pattern 38: Can I get you...** (~ 가져다 드릴까요?) ➡️ `a menu?` / `a drink?` / `a chair?` / `a towel?` / `anything?` [12].
  * **Pattern 39: I can't wait to...** (~하는 것이 너무 기다려져) ➡️ `go to Paris` / `see you` / `meet them` / `marry you` / `read the book` [12].
  * **Pattern 40: I can't stand...** (~을 견딜 수 없어) ➡️ `the heat` / `the noise` / `the music` / `my boss` / `the traffic` [12].
  * **Pattern 41: It can't be...** (~일 리 없어) ➡️ `difficult` / `true` / `easy` / `possible` / `a coincidence` [10, 12].
  * **Pattern 42: It's just...** (단지 ~일 뿐이야) ➡️ `a joke` / `a dream` / `a movie` / `an idea` / `a coincidence` [10, 12].
  * **Pattern 43: It's time to...** (~할 시간이야) ➡️ `work` / `study English` / `take a break` / `sleep` / `eat` [10, 12].
  * **Pattern 44: It's hard to...** (~하기 어려워) ➡️ `remember` / `believe` / `explain` / `understand` / `wake up early` [12].
  * **Pattern 45: It's worth...** (~할 만한 가치가 있어) ➡️ `the effort` / `a try` / `the wait` / `taking a risk` / `the price to buy` [12].
  * **Pattern 46: It's impossible to...** (~하는 것은 불가능해) ➡️ `win that game` / `arrive on time` / `prove that theory` / `finish this work` / `solve this problem` [12-14].
  * **Pattern 47: There's a...** (~이 있어) ➡️ `rumor` / `plan` / `reason` / `difference` / `big sale` [13, 14].
  * **Pattern 48: Is there a... / Is there anything else?** (~이 있나요?) ➡️ `a good restaurant?` / `a problem?` / `anything else?` / `a restroom nearby?` / `an ATM in this building?` [13, 14].
  * **Pattern 49: There's nothing...** (아무것도 없어) ➡️ `wrong` / `left in the fridge` / `to worry about` / `to tell` / `to do` [14].
  * **Pattern 50: There must be...** (틀림없이 ~이 있을 거야) ➡️ `a solution` / `a misunderstanding` / `a reason` / `a problem` / `a mistake` [14].
- **주요 인용**: > "Pattern 41: It can't be...
It can't be difficult (그것이 어려울 리 없어)
It can't be true (그것이 사실일 리 없어)" [10]

### ### 4. 인과, 의무, 수량 확인, 반문 및 의견 표출 패턴 (Pattern 51 ~ 100)
- **핵심 논지**: 사건이 일어난 인과적 이유 고지(`That's why`), 필요와 의무의 수준 조율(`You have to`, `You don't have to`), 타인의 의견 타진 및 반문 수사, 그리고 자신의 말과 의도를 명확히 정렬해 다시 선언할 때 쓰는 문형들이다 [15-17].
- **근거 및 데이터**:
  * **Pattern 51: That's why...** (그래서 ~한 거야) ➡️ `I called you` / `we are here` / `I'm late` / `it's important` / `I like you` [14].
  * **Pattern 52: This is the only...** (이것이 유일한 ~야) ➡️ `hope` / `way` / `clue` / `answer` / `reason` [14].
  * **Pattern 53: There's no time to...** (~할 시간이 없어) ➡️ `explain` / `worry` / `waste` / `hesitate` / `stay` [14].
  * **Pattern 54: I've got...** (~이 있어) ➡️ `work to do` / `dream` / `headache` / `meeting at 2 p.m.` / `good idea` [14].
  * **Pattern 55: I've already...** (이미 ~했어) ➡️ `made plans` / `done my homework` / `eaten breakfast` / `arrived` / `seen that movie` [14, 15].
  * **Pattern 56: Have you ever...** (~해 본 적 있니?) ➡️ `been to Paris?` / `seen his cat?` / `rented a car?` / `met him?` / `driven a car?` [14, 15].
  * **Pattern 57: You have to...** (~해야 해) ➡️ `study` / `go home` / `stop smoking` / `exercise hard` / `win the game` [14, 15].
  * **Pattern 58: You don't have to...** (~할 필요 없어) ➡️ `worry` / `change` / `be perfect` / `beg` / `memorize it` [15, 18, 19]. *(※ 256번에서는 부정-약한 강제의 표현으로 표기됨)*
  * **Pattern 59: Do I have to...** (내가 ~해야 하나요?) ➡️ `wear a tie?` / `go?` / `move my car?` / `work on weekend?` / `wear this?` [14, 20].
  * **Pattern 60: Don't be so...** (너무 ~하게 굴지 마) ➡️ `sad` / `serious` / `sure` / `loud` / `stubborn` [20].
  * **Pattern 61: You will have to...** (너는 ~해야 할 거야) ➡️ `wake up early` / `study hard` / `be patient` / `wait` / `be careful` [20]. *(※ 패턴 62로도 혼용 표기됨 [21])*
  * **Pattern 62: You may have to...** (~해야 할지도 몰라) ➡️ `wait` / `take the bus` / `pay` / `come` / `explain it` [20].
  * **Pattern 63: What are you going to...** (무엇을 ~할 거니?) ➡️ `wear?` / `read?` / `make?` / `watch?` / `write?` [16, 20].
  * **Pattern 64: What do you think of...** (~에 대해 어떻게 생각하니?) ➡️ `the idea?` / `my hairstyle?` / `the movie?` / `my English skills?` / `this food?` [16, 20, 22].
  * **Pattern 65: What do you want to...** (무엇을 ~하고 싶니?) ➡️ `eat?` / `know?` / `buy?` / `drink?` / `study?` [20, 23].
  * **Pattern 66: Who else...** (다른 누가 ~하니?) ➡️ `is absent?` / `can go?` / `is there?` / `is coming?` / `has read this book?` [20, 23].
  * **Pattern 67: How about...** (~는 어때?) ➡️ `a break?` / `there?` / `today?` / `calling the police?` / `asking your teacher?` [20, 23].
  * **Pattern 68: How much is...** (~은 얼마인가요?) ➡️ `this?` / `it?` / `the bag?` / `the food?` / `the fee?` [20].
  * **Pattern 69: How was...** (~은 어땠니?) ➡️ `the trip?` / `the movie?` / `that meeting?` / `your weekend?` / `the weather?` [20, 24].
  * **Pattern 70: How can you...** (어떻게 ~할 수 있니?) ➡️ `forget that?` / `be sure?` / `help me?` / `do that?` / `not know?` [20, 24].
  * **Pattern 71: How often do you...** (얼마나 자주 ~하니?) ➡️ `eat?` / `lie?` / `come here?` / `wash your hair?` / `see a doctor?` [20, 24].

## 💡 주요 용어 (Key Terminology)

- **에빙하우스의 망각 곡선 이론 (Ebbinghaus Forgetting Curve Theory)**: 시간의 경과에 따라 뇌에 입력된 습득 정보가 소멸되는 비율을 계산한 정량적 인지과학 모델 [1].
- **누적 반복 학습 (Cumulative Repetitive Learning)**: 단기기억의 완전 소멸을 물리적으로 제어하여 영구 보존용 장기기억 영역으로 밀어 넣기 위한 당일 ➡️ 전날 ➡️ 전전날의 다발적 시차 누적 복습법 [1, 3].
- **뼈대 패턴 (Bones Patterns)**: 문법 용어의 개입 없이 일상 구술의 핵심 줄기가 되는 고정된 문장 전단 골격 (예: *I'm about to, You don't want to* 등) [3, 41, 42].
- **살 표현 (Flesh Expressions)**: 고정된 문장 뼈대 뒤에 융착 결합하여 구술을 완성하고 풍성하게 보완해 주는 하위 단어, 구, 절 성분들 [41, 42].
