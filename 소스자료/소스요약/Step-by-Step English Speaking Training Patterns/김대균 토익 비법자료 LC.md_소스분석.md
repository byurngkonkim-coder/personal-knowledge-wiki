# 📄 김대균 토익 비법자료 LC.md (Part: 전체)

## 📌 요약 (Executive Summary)
- 본 문서는 토익(TOEIC) LC(듣기 평가)의 핵심 파트인 Part I(사진 묘사), Part II(질의응답), Part IV(짧은 설명문)를 완벽히 공략하기 위한 실전 유형 분석과 비법 코드들을 체계적으로 수립한 수험 비법서이다.
- 부가의문문(Tag Questions)의 긍정/부정 판단 법칙, 짧은 설명문(Short Talks)의 3대 질문 범주(일반 정보, 구체적 정보, do-next 정보)와 논리 전개 방식, 그리고 출제자의 오답 설계 장치(속이기)를 구체적으로 규명하고 있다.
- 무손실 보존 원칙에 의거하여, 원본에 수록된 고유 영어 예문, 비법 코드 명칭, 특수 문자 및 기호, 그리고 텍스트 중간에 끊겨 기재된 문장 파편("81. What is the Marias job?")을 단 하나의 누락이나 요약 없이 100% 원형 전사하여 박제한다.

## 🧱 상세 분해 (Detailed Breakdown)

### ### 1. Part I 사진 묘사 (Photographs) 유형 공략법
- **핵심 논지**: 파트 1 사진 묘사 문제의 가장 기본이 되는 의사소통 및 언어화의 기본 단위는 단문(주어+동사)이며, 실제 출제되는 20문제는 모두 단문 형태로만 구성된다.
- **근거 및 데이터**:
  - **유형 Code 1. 단문**: 주어 + 동사로 이루어진 구조로 특정 상황을 묘사하는 데 활용됨.
  - **기출 문장 묘사 사례**:
    - `The man is reaching up for a book.`
    - `A woman is descending on the escalator.`
    - `She is writhing on the board.` *(※ 원고 고유의 단어 표기인 writhing 형태 무손실 보존)*
- **주요 인용**: > "Communication에서 언어화 시키는데 있어서 가장 기본이 되는 문장 단위는 단문이다. 단문이란 주어 + 동사로 되어있는 문장이다."

### ### 2. Part II 질의 응답 (Questions & Responses) - 부가의문문
- **핵심 논지**: 부가의문문(Tag Questions)은 청자의 인정, 동의, 확인을 요구하는 Yes/No 의문문 범주에 귀속되며, 본문 평서문(main sentence)의 긍정/부정 여부에 따라 극적으로 전환되는 정답 도출 논리를 지닌다.
- **근거 및 데이터**:
  - **유형 Code 27. Tag 잡기(부가)**: 매 시험마다 평균 3문제 정도 출제됨.
  - **① 본문 평서문이 긍정인 경우**: 부가의 tag가 따라붙음. 본문 평서문의 동작 성립 여부가 판단의 절대 기준임.
    - 예: `Mr. Ricardo approved the invoice, didn't he?` (리카도 씨가 송장을 승인했으면 Yes, 승인하지 않았으면 No로 정답이 도출되며, Yes/No 뒤에 결합하는 상세 논리 구절을 끝까지 확인해야 함)
  - **② 본문 평서문이 부정인 경우**: 긍정의 tag가 따라붙으며, 우리말의 긍정/부정 대답 체계와 정반대로 반응하므로 극도의 주의가 요구됨. 최소 1문제 이상 반드시 출제됨.
    - 예: `This isn't your first visit to New York City, is it?` (뉴욕시에 처음 오신 것은 아니죠, 그렇죠? 라는 질문에 대해 처음 방문한 것이 아닐 경우 No[예, 처음이 아닙니다], 처음 방문한 것일 경우 Yes[아니오, 처음입니다]로 수렴함)
- **주요 인용**: > "특히 main sentence가 부정이 나올 경우에는 Yes/No의 응답을 정확히 이해하고 그 뒤에 나오는 내용을 Yes/No와 함께 논리적으로 정확하게 일치시킨 것을 잡아낼 수 있어야 한다."

### ### 3. Part IV 짧은 설명문 (Short Talks) - 기본 지문 규격 및 정보 카테고리화
- **핵심 논지**: 파트 4 짧은 설명문의 기본 길이 및 출제 세트 규격을 명시하고, 출제되는 모든 질문의 구조를 3대 정보 카테고리로 정형화하여 사전 분석한다.
- **근거 및 데이터**:
  - **지문 기본 규격 (비법 Code 1)**: 단어 길이 50~100개 사이, 시간 30초 이내, 지문당 평균 3~8문장 길이로 제한됨. 총 20문항 출제.
  - **출제 지문 수 세트 비중**: 통상적으로 **[2문제짜리 지문 7개(14문항) + 3문제짜리 지문 2개(6문항) = 총 20문항]** 체제로 출제됨. (단, 2001년도 2월 시험에서 2문제짜리 4개, 3문제짜리 4개가 출제된 이례적인 예외가 지난 3년 동안 딱 한 차례 있었음)
  - **3대 질문 정보 카테고리 (비법 Code 3)**:
    1. **일반적 정보 (General Information)**: 6하 원칙에 의거한 화자/그룹/기업체(Who), 전달 시점(When), 발생 장소(Where), 전달 대상(Whom), 핵심 전달 목적 및 주제(What/Why)를 탐색함.
    2. **구체적 정보 및 사례 (Specific Information)**: 질문 속에 정답을 도출하기 위한 단서(Key 어구)가 미리 내포되어 출제됨 (비법 Code 5).
    3. **후속 행동 지시 정보 (Do-next Information)**: 지문을 들은 청자가 앞으로 수행해야 할 직접적 지시사항, 의무, 혹은 이후에 발생할 사건을 탐색함.
- **주요 인용**: > "한 지문은 일반적인 정보(general information)에 관한 1문제 구체적인 사례(specific information)에 관한 1문제로 구성되어 있으며, 이러한 구성 형식을 가진 지문이 7개가 출제된다."

### ### 4. Part IV 짧은 설명문 (Short Talks) - 실전 문제 풀이 비법 코드 (Code 2, Code 6 ~ Code 15)
- **핵심 논지**: 청취 전 사전 문제 읽기 기법, 청취 진행 중 연필과 시선의 고정법, 출제자의 오답 구성 기법, 그리고 응급상황 발생 시의 위기관리 전술을 포괄적으로 다룬다.
- **근거 및 데이터**:
  - **비법 Code 2**: 파트 4의 Direction(약 30초) 시간 동안 미리 최소 3문제의 지문 유형 및 key sentence 위치를 예상하며 선독해해야 함.
  - **비법 Code 6**: Do-next 질문 형태의 정답 단서는 반드시 지문의 최후반부(마지막 문장)에 직접 배치됨.
  - **비법 Code 7 (출제자의 오답 설계 장치)**: 정답 이외의 오답 선택지 3개는 청자가 듣기 도중 귀에 가장 쉽게 걸리도록 지문 속에 직접 출현한 매력적인 어구들을 변형 삽입하여 구성함.
  - **비법 Code 8 (연필과 시선의 실시간 이동)**: general -> specific -> do-next 순으로 논리가 전개되는 고정성이 존재하므로, 연필 끝은 항상 현재 성우가 읽고 있는 정답 단서 질문 위치의 보기 항목으로 기민하게 하향 이동하여 대기해야 함.
  - **비법 Code 9**: 선택 문항에 수(Number) 관련 표현이 존재할 때, 지문 내에서 수 어구가 1개만 발화되면 그것이 즉시 정답이며, 여러 수가 열거 발화된다면 specific information 문제에 해당하므로 Wh- 질문 속의 구체적 사례 단어와 동시 매칭되는 문장의 앞뒤를 청취해야 함.
  - **비법 Code 10**: 'What is NOT mentioned?'와 같은 부정형 질문이 출현하면 지문 청취와 동시에 언급된 3개 항목들을 실시간 소거법으로 지워나가 정답을 확정함.
  - **비법 Code 11 & 14**: 지문 청취가 완결되는 즉시 답안지에 기계적으로 표기한 후, 다음 문항으로 넘어가기 전 제공되는 약 8초간의 문제 간 공백 시간을 활용해 다음 2~3문제를 미리 읽어야 함.
  - **비법 Code 12**: 질문과 질문 사이의 정합성과 유기적 관계를 분석하여 정답을 상호 예측할 수 있음.
    - 예시: `81. What is the Marias job?` *(※ 원고 본문에 중도 끊김으로 기재된 파편 형태 무손실 보전)*
  - **비법 Code 13 & 14 (응급 위기 대책)**: 집중력 소진으로 인해 지문이 뭉개져 한 덩어리 파도처럼 밀려오는 위급 고갈 상태에서는 오답 함정(속이기)마저 무시하고, 선택 문항의 보기 단어 중 단 하나라도 지문에서 직접 들리는 항목이 감지되면 지체 없이 마킹하여 생존율을 극대화해야 함.
  - **비법 Code 15**: 실제 시험 이틀 전(금요일 아침 또는 저녁)에 워크맨이 아닌 후진 컴포넌트 스피커 환경을 인위적으로 조성하여 실전 모의고사 완벽한 한 세트를 풀어보는 훈련을 수행해야 하며, 저자의 실전문제집인 'Tangerine Final Practice Test'가 최적의 도구로 제시됨.
- **주요 인용**: > "Had not it been for the conference, Ms Olga... 수동태에 밑줄이라면 한번 능동을 의심해보자... 정답을 찾지 못할 경우에는 여러분들이 귀에 쉽게 들렸던 다른 단어나 구에 의하여 답을 선택하게 된다. 출제자는 이러한 점을 항상 노리고 Short talks의 문제를 출제하게 된다."

## 💡 주요 용어 (Key Terminology)

- **General / Specific / Do-next Information (파트 4의 불변적 3대 정보 축)**: 지문의 시작(일반 개요)부터 중간 세부 팩트(구체적 정보), 마지막 행동 유도(do-next)에 이르기까지 파트 4의 고정된 논리적 전개 방식이자 문제 출제 유형 분류 체계.
- **Writhing on the board (단문 묘사 수사)**: "판서에 몰두하거나 글을 쓰고 있는 주체의 모습"을 나타내고자 사진 묘사에 동원되었으나, 원본 원고에 'writing' 대신 기이하게 인쇄 수록되어 형태 그대로 무손실 복제된 단어쌍.
- **Tag Questions (부가의문문)**: 평서문 뒤에 짧은 의문문 꼬리를 붙여 사실을 확인하거나 동의를 구하는 구문으로, 본문 평서문이 부정을 띨 경우 대답 체계(Yes/No)가 한국어 번역 체계와 완전히 왜곡되는 까다로운 문형.
- **Tangerine Final Practice Test (Tangerine 실전 모의고사)**: 실제 정기 토익 시험 현장에서 촉발되는 음향 장애, 스피커 왜곡, 잡념 엄습 등의 돌발 변수들을 이틀 전에 동일하게 모사하여 격파할 수 있도록 저자가 직접 고안한 실전 LC 대비용 교재 명칭.
