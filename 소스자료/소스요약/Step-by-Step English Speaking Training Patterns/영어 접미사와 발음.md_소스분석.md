**한줄 요약**
> 이 텍스트는 영어 접미사를 일반적으로 **1류(강세 변화)**와 **2류(강세 중립)**로 불리는 두 가지 범주로 나누어 음성적, 구조적 차이를 탐구한다. *-ity* 또는 *-ic*와 같은 **1류 접미사**는 어간의 끝 부분으로 **주 강세를 이동**시키고, 장모음을 단모음으로 줄이는 **삼음절 단축**을 유발하여 단어의 발음을 근본적으로 변화시킨다. 반대로, *-ness* 또는 *-ful*과 같은 **2류 접미사**는 기본 단어의 원래 **강세 패턴과 모음의 질**을 보존하는 중립적인 추가 역할을 한다. 개별 발음을 넘어, 이러한 범주는 복합어에서 **형태소의 순서**를 결정하며, 1류 접미사가 2류 접미사보다 먼저 와야 한다는 언어학적 규칙을 확립한다. 궁극적으로, 저자는 이러한 분류가 영어에서 **단어 형성, 음운 변화, 형태론적 계층** 간의 상호작용을 이해하기 위한 체계적인 틀을 제공함을 보여준다.

# 📄 영어 접미사와 발음.md (Part: 전체)

## 📌 요약 (Executive Summary)
- 본 문서는 영어 단어 형성에 있어 어간에 파생접미사(derivational suffix)가 결합할 때 나타나는 **강세 변동(Stress Shift)**과 **어간 모음의 변화(Vowel Alternation)**, 그리고 **단어 형성(Word Formation)**의 제약 원리를 체계적으로 다룬 학술성 교재이다.
- 접미사를 어간 강세 및 **삼음절 단모음화 현상(Trisyllabic Shortening)**에 미치는 영향에 따라 **'강세 중립 접미사(class II)'**와 **'강세 변동 접미사(class I)'**로 분류하고, 이들이 단어 형성 시 결합하는 순서적 제약(class I + class II 순서 또는 동일 class 연속 결합)을 정밀하게 입증한다.
- 무손실 추출 엔진 원칙에 의거하여, 원본 텍스트에 나타난 각 번호 체계, 예시 단어의 발음 기호 표기("s[ey]n sane", "s[æ]nity"), 도표의 공백 상태 및 누락된 것으로 추정되는 번호들을 일체의 자의적 수정이나 요약 없이 **100% 원형 그대로 보존**하여 전사한다.

## 🧱 상세 분해 (Detailed Breakdown)

### ### 1. 접미사와 어간 강세 (Suffixes and Stem Stress)
- **핵심 논지**: 어간에 파생접미사가 결합할 때, 접미사의 종류에 따라 어간 강세의 위치가 변동되는 부류(강세 변동 접미사)와 변동되지 않는 부류(강세 중립 접미사)로 구분된다.
- **근거 및 데이터**:
  - **기본 예시**:
    - (1) `-ful`: *béauty* \\(\rightarrow\\) *béauti-ful* (강세 변동 없음)
    - (2) `-ian`: *Móngol* \\(\rightarrow\\) *Mongól-ian* (강세가 접미사 바로 앞 음절로 이동)
  - **접미사의 특징**:
    - 파생접미사(derivational suffix)는 일반적으로 결합하는 어간의 품사를 변화시킨다.
    - `-ful`, `-less`: 명사 어간에 붙어 형용사 파생
    - `-ly`: 형용사에 붙어 부사 파생
    - `-ian`, `-ic`: 명사에 붙어 형용사 파생 (단, `-ian`은 '-하는 사람'의 뜻을 가진 명사를 파생시키기도 함)
    - `-ify`: 명사에 붙어 동사 파생
  - **강세의 보존과 변동**:
    - **강세 중립 접미사**: `-ful`, `-ly`, `-less`는 결합 시 강세 변화 없음.
      - 예: *béauty* \\(\rightarrow\\) *béautiful*, *expénsive* \\(\rightarrow\\) *expénsively*, *bóttom* \\(\rightarrow\\) *bóttomless*
    - **강세 변동 접미사**: `-ian`, `-ic`, `-ify`는 결합 시 강세가 해당 접미사 바로 앞 음절로 이동함.
      - 예: *Jeffersónian*, *periódic*, *solídify*
    - **비교 분석 (3)**: *tótal* \\(\rightarrow\\) *tótal-ness* (변동 없음) vs *totál-ity* (바로 앞 음절로 강세 이동)
  - **두 부류의 분류**:
    - **강세 중립 접미사 (stress-neutral suffix)**: `-ful`, `-ly`, `-less`, `-ness`, `-hood` 등
    - **강세 변동 접미사 (stress-affecting suffix)**: `-ian`, `-ic`, `-ify`, `-ity`, `-ous` 등
  - **두 부류의 접미사 예시 목록**:
    - (4) 강세 중립 접미사 예: `-hood` (*lívely* \\(\rightarrow\\) *lívelihood*, *adúlt* \\(\rightarrow\\) *adúlthood*)
    - (5) 강세 변동 접미사 예: `-ous` (*cónifer* \\(\rightarrow\\) *coníferous*, *hómonym* \\(\rightarrow\\) *homónymous*)
  - **강세 변동의 두 가지 패턴 (6)**:
    - **패턴 1**: \\(\sigma\\) + 접미사 (접미사 바로 앞 음절로 강세를 끌어옴)
      - 예: `-ian`, `-ic`, `-ify`, `-ity`, `-al`, `-ion` (예: *órgan* vs. *orgán-ic*)
    - **패턴 2**: 한 음절 건너서 선행하는 음절로 강세를 끌어오는 패턴 (예: `-ous`, `-ive`, `-y`, `-ate`, `-ar` 등)
- **주요 인용**: > "우리는 영어 단어를 익힐 때, 어간에 어떤 종류의 접미사가 붙느냐에 따라 어간의 발음이 달라질 수 있다는 사실을 흔히 발견하게 된다. 여기서 말하는 어간의 발음 변화는 어간 강세의 변동, 어간 자·모음의 변화를 모두 포함하게 된다"

### ### 2. 접미사와 어간 모음변화 (Suffixes and Stem Vowel Alternation)
- **핵심 논지**: 강세 변동 접미사가 결합할 때 어간의 이중모음 또는 장모음이 단모음으로 변화하는 '삼음절 단모음화 현상(Trisyllabic Shortening)'이 발생하지만, 강세 중립 접미사가 결합할 때는 조건이 충족되더라도 이 현상이 일어나지 않는다.
- **근거 및 데이터**:
  - **모음 변화 예시**:
    - 형용사 *s[ey]n* 'sane'에 접미사 `-ity`가 붙으면 어간 모음 [ey]가 *s[æ]nity* 'sanity'와 같이 [æ]로 변함.
    - (7) a. *ser[iy]ne* 'serene' \\(\rightarrow\\) *ser[ɛ]nity* 'serenity'
  - **삼음절 단모음화 현상 (Trisyllabic Shortening)**:
    - 접미사가 결합하면서 어간의 이중모음/장모음이 단모음으로 변화하는 현상.
    - (8) a. [iy] \\(\rightarrow\\) [ɛ]
    - (9) `-ify`: *v[ay]le* 'vile' \\(\rightarrow\\) *v[ɪ]lify* 'vilify'
  - **삼음절 단모음화의 제약 조건**:
    - **첫째 제약**: 변화하는 모음 뒤에는 반드시 음절이 2개 이상 뒤따라야 함.
      - 예: *f[ey]mous* 'famous'는 변하는 모음 뒤에 음절이 1개밖에 없으므로 \*f[æ]mous가 되지 않음. (10) a. *f[ey]me* 'fame', *f[ey]mous* 'famous', \*f[æ]mous
    - **둘째 제약**: 변하는 모음에 뒤따르는 2개의 음절 모두에 강세가 있어서는 안 됨.
      - 예: *v[ay]tálity* 'vitality'는 변하는 모음 바로 뒤의 음절에 강세가 오므로 \*v[ɪ]tálity가 되지 않음.
  - **접미사 부류별 상이한 거동**:
    - 특정 부류의 접미사는 위의 후행 음절 조건을 충족하더라도 단모음화를 일으키지 않음.
      - (11) `-ful`: *[ey]pron* 'apron' \\(\rightarrow\\) *[ey]pronful* 'apronful' (단모음화 미발생)
    - **일치성**:
      - **강세 변동 접미사 (Class I)**: `-ity`, `-ify`, `-al`, `-ous`, `-(it)ive`, `-ar` 등은 삼음절 단모음화 현상을 일으킴.
      - **강세 중립 접미사 (Class II)**: `-ful`, `-ly`, `-hood`, `-ship`, `-ism`, `-ist`, `-ize` 등은 삼음절 단모음화를 일으키지 않음.
- **주요 인용**: > "이와 같은 어간 모음 변화는 삼음절 단모음화 현상(Trisyllabic Shortening)으로 알려진 것으로서, 접미사로 붙음으로 인해 어간의 이중모음 내지는 장모음이 단모음으로 변화하는 것이다."

### ### 3. 단어형성과 관련하여 (Word Formation Rules)
- **핵심 논지**: Class I(강세 변동)과 Class II(강세 중립) 두 부류의 접미사는 단어 형성 시 결합하는 순서(Suffix Ordering)에 엄격한 제약을 보인다.
- **근거 및 데이터**:
  - **접미사의 클래스화 (12)**:
    - 흔히 강세 변동 접미사는 **Class I**, 강세 중립 접미사는 **Class II**로 명명됨.
    - 두 클래스는 어간 강세 변동 유무 및 삼음절 단모음화 발생 유무에 대해 일관되게 대조되는 행동을 보임.
  - **접미사 연속 결합 제약 (13)**:
    - (13) a. *bounti-ful-ness*, *piti-less-ness* (올바른 영어 단어) vs \*bounti-ful-ity, \*piti-less-ity (잘못된 영어 단어)
    - (13) b. *universal*, *periodic*의 경우에는 `-ness`, `-ity` 중 어떤 명사형 접미사를 붙이든지 모두 올바른 형태가 됨.
  - **접미사 결합 순서 규칙 (14)**:
    - 올바른 결합은 같은 클래스의 접미사가 연속되거나, Class I 다음에 Class II가 결합하는 순서여야 한다.
    - Class II 다음에 Class I이 결합하는 순서(Class II + Class I)는 금지된다.
    - (14) ✔어간 + Class II + Class II (예: *bounti-ful-ness*)
    - 예시 해석: \*bounti-ful-ity가 비문법적인 이유는 Class II인 `-ful` 뒤에 Class I인 `-ity`가 결합했기 때문임.
- **주요 인용**: > "영어에서의 접미사 연결 순서는 같은 class of 접미사가 계속되든지, class I, class II 순서로 연결되어야 한다는 결론을 내릴 수 있다."

## 💡 주요 용어 (Key Terminology)

- **강세 중립 접미사 (Stress-neutral Suffix / Class II Suffix)**: 어간에 결합하더라도 본래 어간이 가지고 있는 강세(Stress)의 위치에 어떠한 변동도 야기하지 않는 접미사 (예: `-ful`, `-ly`, `-less`, `-ness`, `-hood`).
- **강세 변동 접미사 (Stress-affecting Suffix / Class I Suffix)**: 어간에 결합함으로써 어간 강세의 위치를 자신의 바로 앞 음절 또는 한 음절 건너 선행하는 음절로 변동시키는 접미사 (예: `-ian`, `-ic`, `-ify`, `-ity`, `-ous`).
- **삼음절 단모음화 현상 (Trisyllabic Shortening)**: Class I 접미사가 결합할 때, 변동 모음 뒤에 두 개 이상의 비강세 음절이 뒤따르는 경우 어간의 장모음이나 이중모음이 단모음으로 축소 및 약화되는 현상 (예: *sane* [ey] \\(\rightarrow\\) *sanity* [æ]).
- **파생접미사 (Derivational Suffix)**: 일반적으로 결합하는 어간에 붙어 단어의 품사를 변화시키며 새로운 의미적 단어를 파생시키는 접미사.
- **접미사 결합 순서 제약 (Suffix Ordering Restriction)**: 영어의 단어 형성 과정에서 여러 접미사가 결합할 때, Class I이 항상 Class II보다 먼저 어간에 결합해야 하고 Class II 뒤에 Class I이 결합할 수 없다는 규칙.
